# Warlords: Хроники Короны

Пошаговая фэнтези-стратегия в духе классической **Warlords II** — веб-версия.
Карта рисуется процедурно прямо на canvas (пиксель-арт кодами), внешние ресурсы не используются.

## Запуск

```bash
npm install     # не обязателен, только для dev-зависимостей
npm start       # http://localhost:5173
```

Или просто открыть `index.html` в браузере (режим `file://` также поддерживается).

## Возможности

- 3 сценария: **В долине** (24×16, 2 державы), **Дороги к короне** (30×20, 3 державы), **Корона** (34×22, 4 державы).
- 4 державы: Аквилония (люди), Морвейн (тёмные эльфы), Каменный Круг (гномы), Орды Кхарга (орки).
- 8 типов войск, герои с опытом, города с очередями производства, руины / храмы / рудники.
- Бой по раундам с событиями (удары, смерти, исцеление) и воспроизводимым пошаговым боем.
- 3 уровня сложности ИИ: `easy` / `normal` / `hard` (доход, порог победы, герои, разведка).
- Сохранение (localStorage, ключ `warlords_kb_save_v1`), автосохранение, продолжение.
- Синтезированный звук (WebAudio) и процедурная графика.

## Управление

| Клавиша | Действие |
|---|---|
| ЛКМ | выбрать отряд / город / клетку; повторный клик — движение/атака |
| ПКМ / Esc | отмена выделения |
| Пробел | завершить ход |
| N | следующий отряд |

## Структура

- `js/util.js` — хелперы;
- `js/data.js` — фракции, юниты, сложности, террейн;
- `js/scenarios.js` — сценарии;
- `js/mapgen.js` — генерация карты;
- `js/state.js` — состояние, движок, сохранение;
- `js/combat.js` — бой;
- `js/actions.js` — движения, захват, производство, герои;
- `js/ai.js` — ИИ;
- `js/art.js` — процедурная генерация пиксель-арта;
- `js/render.js` — отрисовка карты, фиксированное поле, миникарта;
- `js/audio.js` — звуковые эффекты;
- `js/ui.js` — экраны и логика UI;
- `js/battle-ui.js` — модалка боя;
- `js/modals.js` — модалки (об игре, пауза, поражение/победа);
- `js/main.js` — точка входа;
- `tests/run.js` — автоматические проверки;
- `tests/art-preview.html`, `tests/desktop.html` — превью.
